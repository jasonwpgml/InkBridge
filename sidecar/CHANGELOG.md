# InkBridge Sidecar판 변경 기록

## 검증 기록 — 2026-10-22

- Apple Swift 6.4 / Swift 5 언어 모드, arm64 macOS 13 타깃 빌드 성공.
- 모델 테스트 48개, 렌더링 테스트 15개 — 총 63개 검증 통과.
- 글래스 도구 막대의 접기·펼치기, 재실행 후 접힌 상태 복원, 필기/조작 전환 확인.
- 0.1 사용자 실기: iPad Apple Pencil로 선이 정상 출력되고 MacBook 화면에도 동일 위치에 나타남.
- 로컬 코드 서명 및 Info.plist 형식 검증 통과.
- deslop-review의 자동 검사기는 Swift 프로젝트를 지원하지 않아 직접 Swift 빌드·테스트 및 소스 검수를 수행했습니다. 0.6에서 사용하지 않는 제스처 표시 플래그를 제거했고, 0.6.2 포인터 검수에는 추가 삭제할 항목이나 제거한 입력 검증 가드가 없습니다. 원본 백업은 작업 폴더에 보존했습니다.

## 실기 확인 상태

- 0.2의 Pencil Pro 더블탭은 사용자 테스트에서 반응이 없었습니다. macOS의 Sidecar 더블탭 옵션은 이미 켜져 있음을 UI에서 확인했습니다.
- 0.4.1에서 필기판의 nonactivatingPanel 속성을 제거한 뒤 사용자가 더블탭 전환 성공을 확인했습니다. 0.5에서도 이 AppKit changeMode 처리 경로를 유지합니다.
- UI 자동화는 투명 필기판 드래그에서 `windowNotFoundAtPosition`을 반환했습니다. 이를 펜 입력 성공으로 기록하지 않았습니다. 렌더링과 지우개는 별도 테스트로 검사했습니다.
- Sidecar 지연 수치는 측정하지 않았습니다. 곡선·캐시 개선이 Goodnotes 수준의 체감을 보장하지는 않습니다.
- iPad 네이티브 앱과 문서 동기화 모드는 아직 구현하지 않았습니다. 구성안과 제약은 RESEARCH.md의 후속 설계를 참고하세요.

## 0.3.1 변경

- 유리 바탕이 없는 시안은 사용하지 않습니다. macOS 26의 NSGlassEffectView로 흐림·광학 반사가 있는 Liquid Glass 표면을 제공합니다.
- 펼치기/접기: 0.28초 크기 전환에 도구·화살표 페이드를 조합했습니다. 애니메이션 중 중복 전환을 막고 macOS의 동작 줄이기를 존중합니다.
- 더블탭 이벤트를 한 곳에서 처리하고 소비해 중복 전환을 막습니다. 필기 시작·직접 펜 입력·Fn 임시 조작 후 복귀 시 필기 앱의 포커스를 복원합니다.
- 빌드와 서명 확인, 기존 45개 검증 통과. UI에서 접기·펼치기 후 전체 도구 복원과 유리 바탕을 확인했습니다. 손쉬운 사용·Sidecar·디스플레이 시스템 설정은 변경하지 않았습니다.

## 0.4 변경

- 맑은 유리잔 느낌에 맞춰 macOS 26의 Clear Liquid Glass로 변경했습니다. 바탕을 제거하지 않고, 얇은 반사광과 약한 안쪽 음영을 그리는 GlassSurfaceView를 함께 사용합니다.
- 반사광은 화면 장식이며 포인터를 추적하거나 화면을 캡처하지 않습니다. 실제 배경 굴절은 macOS의 네이티브 유리 재질이 담당합니다.
- 접힌 상태와 펼친 상태 모두에서 표면과 도구가 정상 표시되는 것을 UI로 확인했습니다. 빌드·코드 서명과 기존 45개 검증을 통과했습니다.


## 0.5 변경과 확인 범위

- 0.4.1의 맑은 유리 방향으로 복원. 불투명해진다는 사용자 피드백을 받은 subduedState 보정은 제거했습니다. 현재는 바깥 유리의 흐림·중앙 착색만 조정하며 버튼 내부 필터는 건드리지 않습니다.
- 얕은 가장자리 홈, 기존 접기·펼치기 애니메이션 유지.
- 더블탭 성공은 사용자 확인. 지우개 선택을 분홍색으로 표시하고 지우개 아이콘·커서를 추가.
- SwiftUI의 macOS 14.5+ 공식 스퀴즈 처리와 원형 도구 선택기를 연결. AppKit 더블탭을 중복 수신하는 SwiftUI 더블탭 핸들러는 추가하지 않았습니다.
- 입력 진단에는 펜 식별·압력·changeMode·SwiftUI 스퀴즈 완료와 앱 활성 상태가 표시됩니다. 키 입력, 화면, 좌표는 기록하거나 전송하지 않습니다.
- 원형 도구의 표시와 지우개 선택을 UI로 확인. 기존 모델 36개·렌더링 9개 검증, 빌드·서명·plist 통과. 실제 스퀴즈와 필기 전후 유리의 외관은 확인 대기.
- 무선 Sidecar 사용 및 iPad 기본 앱의 Pencil Pro 정상 동작은 사용자 답변으로 확인. 종단 간 지연은 측정하지 않았고 이번 버전에서 필압 렌더링·예측 입력·네이티브 iPad 문서 모드를 추가하지 않았습니다.

## 0.5.1 변경과 확인 범위

- 기본 필기 화면과 도구 막대 위치를 Sidecar 우선으로 변경. 재실행 직후 ‘Sidecar Display (AirPlay)’가 선택되는 것을 확인했습니다.
- 스퀴즈로 이미 열린 원형 도구를 다시 요청하면 그대로 유지합니다. 이전에는 두 번째 호출이 도구를 닫았지만, 이것이 실기에서 안 보였던 원인인지는 확인되지 않았습니다.
- 화면을 교체할 때 이전 필기 창과 SwiftUI 뷰를 정리하고, 이전 캔버스의 콜백은 무시합니다. 진단에는 스퀴즈의 눌림·완료·취소 단계를 구분합니다.
- 앱 창 제목에 버전을 표시합니다. 0.5.1로 종료·재실행했으며 기존 2획을 파일에 저장한 뒤 복원했습니다.
- 빌드, 모델 36개·렌더링 9개 검증, 로컬 서명·plist 검사 통과. 유리의 외관 유지와 실제 스퀴즈의 원형 도구 표시는 아직 검증되지 않았습니다.

## 0.5.2 — 맑은 유리의 화면 반영 수정

- 필터 내부 값이 이미 목표 값이어도 화면에 같은 값이 반영돼 있다고 가정하지 않습니다. `CALayer`의 명명된 필터 경로로 매 프레임 값을 전달하고 필터 목록을 갱신합니다.
- 같은 배경의 세 표면을 비교했습니다. 기존 방식과 macOS 기본 재질은 뿌옇게 보였고, 수정 방식은 배경의 선명함과 가장자리 굴절을 유지했습니다. 다른 창을 활성화한 뒤에도 이 차이를 확인했습니다.
- 블러·중앙 착색의 목표 값, 굴절과 홈, 접기 애니메이션은 변경하지 않았습니다. 변경 범위는 유리 갱신 방식과 버전 번호입니다.
- 0.5.2 실행 확인. Swift 빌드, 모델 36개·렌더링 9개, 코드 서명·plist 검사 통과. 검증용 앱은 종료했습니다. 시스템 설정은 변경하지 않았습니다.
- 사용자 실기 확인: ‘필기 시작’과 다른 창 이동 후에도 원하는 투명함이 계속 유지됨. 0.5.2의 표면을 기준 디자인으로 확정했습니다.


## 0.6 — 도구 사용성

- 도구·실행 취소를 첫 줄에, 색/굵기 또는 지우개 방식/범위를 둘째 줄에 배치했습니다. 저장·열기·PNG·전체 지우기·화면 선택은 더보기 메뉴에서 사용합니다. 원형 도구를 여는 버튼을 추가했습니다.
- 부분/획 지우개를 모두 제공합니다. 부분 지우기는 원래 획 위의 마스크로 저장해 선의 곡선·굵기와 화살촉을 보존합니다. 한 번의 지우개 드래그는 한 번에 실행 취소/다시 실행합니다.
- 펜 포인터는 선택한 색과 굵기를 표시하고, 형광펜은 실제 너비를 원으로 표시합니다. 부분 지우개는 실선 원, 획 지우개는 점선 원이며 중심이 실제 지우는 위치입니다. 0.6.2에서 큰 지우개 배지를 없애고 작은 도구 아이콘과 더 얇은 이중 윤곽으로 변경했습니다.
- 밝은/검은 배경 비교에서 얇은 흰 윤곽만으로는 글자와 아이콘 대비가 부족했습니다. 글자·아이콘 바로 뒤에 작은 반투명 받침을 추가했습니다. 도구 막대 전체의 유리 재질은 변경하지 않았습니다.
- 필기 지연·필압·예측 입력 엔진은 변경하지 않았습니다. Sidecar의 손가락 터치 지원 범위도 Mac 앱에서 확장하지 않습니다.
- 원본 소스와 0.5.2 앱은 작업 폴더 `work/inkbridge-v052-backup`에 보존했습니다. 새 빌드는 별도 경로에서 검증 후 적용해 실행 중인 앱 파일을 덮어쓰지 않습니다.

## 0.6.1–0.6.2 — 선택 유지와 포인터

- 굵기/지우개 방식 선택을 화면 갱신 전에 받아 선택이 이전 값으로 돌아가는 문제를 수정했습니다.
- 펜·형광펜·화살표·지우개의 작은 아이콘을 실제 접점에서 떨어뜨려 표시합니다. 중앙 점/범위 원이 실제 위치이며, 아이콘 자체는 필기 위치가 아닙니다.
- 실제로 쓰거나 지우는 동안에는 아이콘이 사라지고 작은 점/얇은 범위 원만 남습니다. 입력이 끝나면 아이콘이 돌아옵니다. 포인터 이미지는 도구 설정 변경 때 만들어 재사용합니다.
- 부분 지우개는 실선, 획 지우개는 점선이며 원 안은 투명합니다. 펜의 큰 십자 표시와 지우개의 사각 배지는 제거했습니다.
- 밝은/검은 배경에서 대기·입력 중 포인터 이미지를 실제 크기로 검수했습니다. iPad에서 실제 입력 중의 표시 전환과 체감은 사용자 확인이 필요합니다.
- 사용자 확인: 0.6의 지우기는 작동하며 포인터 개선을 요청했습니다. 0.5.2의 승인된 유리 소스는 그대로 유지했습니다.
- 이전 38획은 `before-0.6-20261022.inkbridge`, 이후 새 5획은 `before-0.6.2-20261022.inkbridge`에 각각 보관했습니다.

- 0.6.1 UI에서 펜 7pt, 지우개 48pt, 부분↔획 전환이 유지되는 것을 확인했습니다. 0.6.2 빌드·서명·plist 검사를 통과했고 재실행 후 iPad 기본 선택과 새 5획 복원을 확인했습니다.

## 0.6.3 — 스퀴즈 토글과 불투명 모드

- 스퀴즈 완료 이벤트마다 원형 도구를 열거나 닫습니다. 표시 중에도 필기판의 키보드 포커스를 유지해 다음 스퀴즈를 받을 수 있게 했습니다. 실제 Pencil 이벤트 수신은 iPad에서 확인해야 합니다.
- 글자와 아이콘 뒤에 붙였던 흰 받침을 제거했습니다. 원형 도구에서 선택한 도구의 색 강조는 유지합니다.
- 반원 버튼의 불투명 모드를 켜면 도구 전체에 기본 macOS 배경 흐림을 적용합니다. 끄면 기존 맑은 유리를 사용합니다. 선택은 재실행 뒤에도 유지됩니다. macOS 26 이전에서는 기본 흐림 재질을 사용합니다.
- 배경 모드를 전환할 때 새 재질 뷰를 만들므로 맑은 유리의 내부 필터 설정이 불투명 모드에 남지 않습니다.
- 모델 48개·렌더링 15개 검증 및 빌드 통과. 원본은 `../../work/inkbridge-before-063/`에 보관했습니다.
- 0.6.3 UI 검수: 흰 받침 제거, 불투명↔맑은 유리 전환, 재실행 후 불투명 모드 유지 확인. iPad 화면에 다시 실행하고 필기 모드를 켜 두었습니다. 실제 Pencil의 반복 스퀴즈 수신은 사용자 실기 확인이 남아 있습니다.


## 0.6.4 — 필기 렌더링 최적화 (2026-10-26)

- 펜·형광펜은 진행 중인 획의 확정된 곡선 경로를 재사용하고, 끝의 임시 선분만 갱신합니다. 새 선분 주변을 다시 그리며, 화살표는 이동 전후의 화살촉까지 포함합니다. 선 모양과 최신 입력점까지 이어지는 동작을 유지합니다.
- 획을 마칠 때 기존 필기 전체를 다시 그리지 않고 비트맵에 새 획만 추가합니다. 지우기·실행 취소·파일 교체·화면 크기 및 배율 변경 때는 전체 캐시를 다시 만듭니다. 저장 한도나 중복 ID로 거부된 획은 캐시에 추가하지 않습니다.
- 지우개가 문서를 바꾸지 않은 입력에서는 화면 갱신과 캐시 재생성을 생략합니다. 지우개 제스처 한 번을 한 번에 실행 취소하는 동작은 유지합니다. 실제로 지워졌을 때의 전체 캐시 재생성과 전체 획 충돌 검사는 후속 개선 대상입니다.
- 승인된 유리 재질의 매 프레임 필터 처리는 그대로 유지했습니다. Sidecar 전송·Pencil 이벤트 처리·파일 형식은 변경하지 않았습니다. 새 Mac+iPad 네이티브 버전의 JPEG 전송 최적화는 별도 작업입니다.
- `./test.sh`: 모델 56개·렌더링 331개, 총 387개 통과. 펜·형광펜·화살표의 입력 단계별 1×/2× 이미지, 겹침·부분 지우기·실행 취소·리사이즈·캐시가 없는 첫 획을 확인했습니다. 전체 경로와 완성된 캐시는 픽셀 단위로 일치합니다. 부분 갱신은 Quartz의 클리핑 경계 반올림 차이로 채널당 최대 2/255를 허용하고, 같은 경로를 전체 렌더링할 때는 정확한 픽셀 일치를 별도로 검사합니다.
- 캔버스 입력 경로 격리 검사 10개도 통과했습니다. 실제 `InkCanvas`에 테스트용 컨트롤러를 연결해 입력 종료·캐시 추가·지우기·실행 취소·거부된 중복 획을 확인한 보조 검사이며, 실제 Pencil 입력 검사는 아닙니다. 소스는 `../../work/inkbridge-performance-064/canvas/`에 있습니다.

### 로컬 합성 부하 측정

같은 Mac에서 최적화 컴파일(`swiftc -O`)한 0.6.3과 0.6.4를 번갈아 3회 실행했습니다. 1280×800pt, 2× 비트맵에 각 240점인 200획을 먼저 그리고, 현재 획의 1200개 입력과 20획 추가를 측정했습니다. 화면 전체에 겹치는 선이 많은 부하 시험이며 실제 Sidecar·Pencil 왕복 지연을 뜻하지 않습니다. 실행 중 시스템 부하에 따라 편차가 있습니다.

| 처리 | 0.6.3 | 0.6.4 |
|---|---:|---:|
| 입력 1회 렌더링 평균의 중앙값 | 4.107ms | 0.055ms |
| 획 추가 처리 평균의 중앙값 | 305.131ms | 1.948ms |
| 획 추가 처리 평균의 3회 범위 | 151.7–332.9ms | 1.6–10.9ms |

200획에 20획을 추가한 최종 비트맵의 SHA-256은 수정 전후 모든 실행에서 일치했습니다. 실제 iPad의 필기감·반복 스퀴즈·장시간 사용은 확인 대기입니다.


## 0.6.5 — 필기 도구 선택 (2026-10-26)

- 펜·형광펜·화살표·지우개에 이름과 선택 표시를 붙이고, 도구 버튼은 54pt, 색상·주요 동작 버튼은 44pt로 넓혔습니다. 색상과 세 가지 굵기는 메인 패널에서 바로 고릅니다.

- 선택한 필기 도구를 다시 누르거나 굵기 숫자 옆 설정 버튼을 누르면 선 미리보기, 세밀한 굵기 조절, 12색 팔레트가 열립니다. 추가 색상을 고르면 메인 패널 마지막 색상 칸에도 표시됩니다.
- 기존 유리 재질·불투명 모드·원형 도구·Pencil 입력 경로·0.6.4 렌더링 최적화를 유지했습니다. 설정창에서는 캔버스 입력을 잠시 멈추고, 닫으면 이전 필기 모드로 돌아갑니다.
