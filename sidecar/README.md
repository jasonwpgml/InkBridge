# InkBridge Sidecar판 (0.6.5)

맥의 웹페이지·앱 화면 위에 쓰는 필기 앱입니다. 아이패드는 Sidecar 화면과 Apple Pencil 입력 장치로 사용합니다.

## 지금 실행하기

이 폴더에서 `./build.sh`를 실행하면 `InkBridge.app`이 생깁니다. 더블클릭해 실행합니다.

- Apple Silicon Mac, macOS 13 이상을 대상으로 빌드했습니다.
- 빌드 스크립트는 임시 서명(ad-hoc)만 합니다. App Store 배포·공증된 앱은 아닙니다.
- 아이패드용 앱 설치나 개발자 계정은 필요하지 않습니다.
- 디스플레이 설정, 로그인 항목, 접근성 권한을 자동으로 바꾸지 않습니다.
- Sidecar가 연결돼 있으면 iPad 화면을 기본으로 선택하고 그 화면 위쪽에 도구 막대를 띄웁니다. 없으면 맥 내장 화면을 사용합니다. 실행 후 Sidecar를 연결해도 자동으로 옮기며, 앱에서 화면을 직접 고르면 해당 실행 동안 그 선택을 유지합니다.

## 두 가지 사용 방식

| 상황 | 연결과 앱 사용 |
|---|---|
| 평소 작업 | Sidecar를 확장 디스플레이로 사용. InkBridge는 조작 모드로 두거나 종료 |
| 강의 중 필기 | Sidecar에서 맥 내장 화면 미러링. InkBridge의 필기할 디스플레이를 확인한 뒤 필기 시작 |

아이패드에서 맥으로 AirPlay를 추가 연결할 필요는 없습니다. Sidecar 자체가 Pencil 입력을 맥으로 전달합니다. 현재 사용자의 실제 기기에서 아이패드에 쓴 선이 맥북에도 같은 위치에 표시되는 것을 확인했습니다.

## 조작

| 동작 | 방법 |
|---|---|
| 필기 / 원래 앱 조작 | ‘필기 시작’ / ‘조작으로’ 또는 `⌥⌘D` |
| 잠깐 원래 앱 클릭·스크롤 | `Fn`을 누른 동안 조작, 놓으면 필기 복귀 |
| 조작 모드로 돌아오기 | 필기판에 키보드 포커스가 있을 때 `Esc`, 또는 마우스 오른쪽 버튼 |
| 실행 취소 / 다시 | `⌥⌘Z` / `⌥⇧⌘Z` 또는 도구 막대 버튼 |
| 현재 화면 필기 전부 지우기 | `⌥⌘⌫` 또는 ‘모두 지우기’. 실행 취소 가능 |
| 도구 막대 접기 / 펼치기 | 오른쪽 위 화살표. 크기 변화와 도구 페이드 애니메이션. 접은 상태는 다음 실행에도 유지 |
| Pencil 더블탭 | 현재 필기 도구 ↔ 선택한 지우개. 부분/획 방식은 유지. 지우개는 분홍색 선택 표시와 실제 범위를 보여주는 속 빈 원 |
| Pencil Pro 스퀴즈 | macOS 14.5 이상에서 원형 도구 열기. 다시 누르면 닫기 |
| 불투명 모드 | 도구 막대 오른쪽 반원 버튼. 도구 막대와 원형 도구의 배경 흐림을 전환하고 선택을 저장 |
| 원형 도구 수동 실행 | 도구 막대의 원형 도구 버튼 또는 InkBridge 메뉴 → 빠른 도구. 바깥 클릭 또는 Esc로 닫기 |
| 지우개 방식과 범위 | 지우개 선택 → 아래쪽에서 부분/획 선택, 지름 16·28·48pt |
| 저장·열기·PNG·화면 선택 | 도구 막대의 더보기(…) 메뉴 |
| 제스처 문제 진단 | InkBridge 메뉴 → Pencil 입력 진단. 30초 동안 앱에 도착한 이벤트를 집계. 최근 진단 결과에서 다시 보기 |
| 도구 막대 다시 보기 | 메뉴 막대의 펜 아이콘 → 도구 막대 보기 |

펜·형광펜·화살표·부분/획 지우개, 6색, 굵기 3단계를 제공합니다. 부분 지우개는 범위 안의 잉크만 지우고, 획 지우개는 닿은 획 전체를 지웁니다. 빠른 지우개 이동도 이벤트 사이를 이어서 처리합니다. 도구 막대는 배경을 잡고 옮길 수 있습니다. macOS 26 이상에서는 Apple의 NSGlassEffectView를 사용하고, 이전 버전에서는 반투명 배경을 사용합니다. 도구 막대에는 Clear Liquid Glass를 적용합니다. 중앙의 흰색 덧칠을 제거하고 얕은 가장자리 홈만 추가했습니다. macOS 26에서만 비공개 CAFilter 입력의 존재를 검사해 배경 흐림과 중앙 착색을 낮춥니다. 기본 굴절 효과는 유지합니다. 필터 구조가 달라지거나 투명도 줄이기가 켜져 있으면 기본 재질을 사용하며, 이 조정은 App Store 배포용이 아닙니다. 별도 창 그림자는 없습니다. 시스템 외관 설정은 변경하지 않습니다. 0.6에서는 저장·화면 선택을 더보기로 묶고, 선택한 도구의 설정을 둘째 줄에 표시해 도구 막대의 높이를 줄였습니다.

## 저장

- **저장:** 편집 가능한 `.inkbridge` 파일. 배경 화면은 포함하지 않습니다. 부분 지우기 정보가 있으면 파일 형식 2로 저장하며 InkBridge 0.6 이상에서 열 수 있습니다. 기존 형식 1 파일도 계속 열 수 있습니다.
- **열기:** 현재 선택한 화면의 필기를 저장 파일로 교체합니다. 다른 화면의 필기는 유지합니다.
- **PNG:** 배경 없는 필기 이미지입니다.
- **화면과 필기를 함께 캡처:** macOS의 `⌘⇧3` 또는 `⌘⇧4`를 사용합니다.

필기는 자동 저장되지 않습니다. 종료 전에 필요한 내용을 저장하세요. 내용이 남아 있으면 종료할 때 안내합니다.

## 알아둘 점

- 필기는 화면 위치에 고정됩니다. 웹페이지를 스크롤해도 문장을 따라 이동하지 않습니다.
- Zoom·OBS에서는 전체 디스플레이 또는 화면 영역을 공유해야 별도 필기 창까지 포함됩니다. 단일 앱 창 공유에는 필기가 빠질 수 있습니다.
- Sidecar가 확장 모드이면 선택한 화면에만 필기합니다. 두 기기에 같은 화면이 필요할 때는 미러링을 사용하세요.
- 디스플레이 연결·해상도가 바뀌면 정규화 좌표로 다시 표시합니다. 화면의 가로세로 비율이 달라지면 모양이 늘어날 수 있습니다.
- 창 이동이나 가상 데스크톱 전환에 맞춰 필기가 자동으로 따라붙는 기능은 없습니다.
- 일부 앱이 쓰는 전역 단축키와 충돌하면 도구 막대 버튼을 이용하세요. Fn의 macOS 이모티콘 동작은 앱에서 변경하지 않습니다.
- 기존 필기는 Retina 해상도의 이미지로 재사용하며 완성한 획만 추가합니다. 현재 획은 이미 계산한 곡선 구간을 보관하고 새 선분 주변만 다시 그립니다. 점 사이의 곡선 보간과 지우개 판정은 같은 경로를 사용합니다. 선 끝은 최신 입력 위치까지 표시합니다.
- 스퀴즈는 SwiftUI의 공식 onPencilSqueeze로 수신합니다. 0.5 실행 화면에서 ‘스퀴즈 수신됨’을 확인했습니다. 원형 도구의 수동 표시·클릭은 검증했지만, 실제 스퀴즈로 도구가 나타나고 유지되는지는 0.5.1에서 실기 확인이 필요합니다.
- 0.5.2는 유리 필터의 값을 렌더링 레이어에도 매 프레임 반영합니다. 비교 창에서 기존 방식의 뿌연 표면을 재현했고 수정 방식은 다른 창을 활성화한 뒤에도 선명함을 유지했습니다. 사용자가 이 비교의 가운데 재질을 선택했으며, 실제 앱에서도 필기 시작·다른 창 이동 후 원하는 투명함이 계속 유지된다고 확인했습니다.
- 현재 버전은 일정한 굵기로 그립니다. Pencil 필압·기울기·호버·자동 지우기·화면 확대·배경 캡처는 구현하지 않았습니다.
- 실제 Pencil 입력과 맥북 동시 반영은 사용자 확인을 받았습니다. 모든 전체 화면 앱·다중 디스플레이 조합을 시험한 것은 아닙니다.

## 소스와 빌드

추가 패키지가 필요 없는 Swift/AppKit 앱입니다. Apple Command Line Tools의 Swift 컴파일러로 빌드합니다.

```sh
./build.sh
./test.sh
```

- `Sources/main.swift`: 투명 필기판, 도구 막대, 전역 단축키, 파일 선택, 연습장
- `Sources/InkRendering.swift`: 선 렌더링과 Retina 이미지 캐시
- `Sources/InkModel.swift`: 획 데이터, 지우개 충돌, 편집 기록, 파일 검증
- `Sources/InkCursor.swift`: 도구별 포인터와 글자·아이콘 대비
- `Tests/main.swift`: 실행 취소 분기, 지우기 묶음, 선분·탭·화살촉 충돌, 파일 복원·잘못된 입력 검증
- `RESEARCH.md`: 앱 조사, iPad 앱 배포 경로, REA 근거와 구현 범위

변경 기록과 검증 기록은 [CHANGELOG.md](CHANGELOG.md)에 있습니다.
