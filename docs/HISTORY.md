날짜별 변경과 그때 확인한 범위입니다. 최신이 위에 있습니다. 로그 파일(`build/…`)은 저장소에 포함하지 않습니다.

## 검증 기록 (맥 화면·서재)

- 2026-10-28 (맥 앱 처음 화면): InkBridge Mac 창을 iPad 처음 화면처럼 로고와 모드 카드 두 개(**화면 보내기**·**책장 열기**)로 바꾸고, 카드마다 상태(연결 코드·연결된 iPad·보내는 중 / 열려 있음·닫혀 있음)를 보여 주며, 누르면 각 화면이 열립니다(`Mac/MacWindow.swift`). 패널은 기본이 불투명이고, 톱니바퀴의 불투명 모드를 끄면 Liquid Glass(macOS 26, 이전은 반투명 재질)가 됩니다(`Mac/MacSurfaces.swift`). iPad의 로고·잉크 배경은 `Shared/InkBrand.swift`로 옮겨 함께 씁니다. `build/`의 앱을 `-appearance`·`-macMode`·`-opaqueSurfaces` 실행 인자로 열어 처음 화면(불투명 라이트·다크, 유리 라이트·다크), 화면 보내기 화면, 책장 열기 화면(닫힘·열림)을 창 스크린샷으로 확인했고, Xcode로 맥·iPad 빌드를 통과했습니다. 카드·버튼을 직접 눌러 보지는 않았습니다.
- 2026-10-28 (책장 연결 표시·맥 앱 서재 서버): 서재 통로의 맥 책장 이름표 아래에 연결됨·연결 안 됨·확인 중을 표시하고, 연결 안 된 책장의 앞면을 어둡게 했습니다(서재가 열려 있는 동안 20초마다 `GET /__pr/api/info`로 확인). 맥 앱 InkBridge Mac에 **서재 서버** 칸을 넣어 폴더를 고르면 서버가 열리고 iPad 주소(복사 버튼)를 보여 줍니다(`Mac/LibraryHost.swift`). 서버 파일은 빌드 때 앱에 넣고(`scripts/bundle-library.sh`) 실행 때 Application Support로 복사해 씁니다. 시뮬레이터에서 연결된 책장·연결 안 된 책장 두 가지를 스크린샷으로 확인했습니다. 맥에서는 `build/`의 앱으로 5173이 이미 쓰이는 상태에서 5174로 열리는 것, 창의 주소 표시, 서버 응답(`/__pr/api/info`·책 목록), 앱을 강제 종료한 뒤 다시 열면 남은 서버를 닫고 같은 포트로 다시 여는 것을 확인했습니다. 폴더 고르기 창·서재 닫기 버튼·주소 복사를 직접 눌러 보지는 않았고, `/Applications`의 맥 앱과 실기 iPad에는 아직 설치하지 않았습니다.
- 2026-10-28 (잠긴 책장 덮개): 공용 클라우드 책장을 젖빛 유리 대신 먼지 덮개 천으로 덮고, 끝판에 ‘공용 클라우드 · 준비 중’ 꼬리표를 달았습니다. 시뮬레이터에서 라이트·다크 화면을 스크린샷으로 확인했고, 실기 iPad는 확인하지 않았습니다.
- 2026-10-27 (서재 책장 통로): 서재를 맥마다 책장 하나씩 서 있는 통로로 바꿨습니다(`iPad/LibraryAisle.swift`). 책장은 도서관 서가처럼 좁은 끝판(맥 이름 이름표)과 책이 가득한 긴 앞면이 안쪽으로 멀어지게 비스듬히 서고, 옆으로 밀면 같은 순서가 끝없이 반복되고, 누르면 앞면이 돌아서며 다가와 그 맥의 책장(이전의 종류별 선반)이 열립니다. 맥 주소를 여러 개 저장하고(이전 단일 주소·`-serverURL`은 책장 하나로 옮김), 서버가 `GET /__pr/api/info`에 맥 이름(`name`)을 알려 줍니다. 공용 클라우드 서재는 젖빛 책장으로 서 있고(10-28에 덮개 천으로 바꿈) 누르면 준비 중이라고 알립니다. 시뮬레이터에서 통로·옆으로 밀기·책장 열고 돌아오기·책장 추가 시트를 확인했고, 서버 검사 27개·맥 컴파일·Sidecar 391개 통과. 층 나누기·서재 고르기·건물은 아직 없고, 다가오는 애니메이션의 중간 모습과 실기 iPad는 확인하지 않았습니다.
- 2026-10-27 (변환 문서 쪽 좌표): PDF·PowerPoint·Word를 변환한 쪽 문서의 필기를 화면 좌표 대신 쪽 이미지 픽셀(쪽 너비 1600)로 저장하고, 화면 크기와 상관없이 문서 버전당 리뷰 하나(viewport 1600×1600)를 쓰게 했습니다. 브라우저에서 1180×820과 820×1180 두 탭으로 같은 위치 표시, 저장된 리뷰 정보를 지운 뒤 서버에서 같은 리뷰 찾기, 실시간 획 전달·지우기, 맥 뷰어(창 크기로 표시)와 PDF 내보내기 위치를 확인했습니다. 서버 검사 26개·맥 컴파일·Sidecar 391개 통과. 이전에 화면 좌표로 쓴 변환 문서 필기는 뷰어·PDF 내보내기에만 나오고 문서를 열면 보이지 않습니다. 실제 iPad Pencil로는 확인하지 않았습니다.
- 2026-10-27 (연결 도움말): 서재의 ‘맥 서버에 연결할 수 없습니다’ 카드·서버 주소 화면에 ?, 문서 안 오류 화면에 ‘연결하는 법’을 넣었습니다. 시뮬레이터에서 세 곳 모두 도움말 시트가 열리는 것을 확인했습니다.
- 2026-10-27 (PDF로 내보내기): 변환 문서를 원본 PDF(PowerPoint·Word는 변환 때 만든 `source.pdf`) 위에 필기를 그린 새 PDF로 내보내는 기능을 웹 ⋯ 메뉴·앱 ⋯ 메뉴(공유 시트)·맥 뷰어에 넣었습니다(`library/lib/pdf-ink.mjs`, `library/scripts/pdf-ink.swift`). 브라우저에서 그린 획이 PDF의 같은 위치에 들어가는 것과 화면 배치 계산(가로·세로 0.01px 이내)을 확인했고, 서명 빌드를 실기 iPad에 설치했습니다. 실기에서 공유 시트와 Word·PowerPoint 파일 내보내기는 확인하지 않았습니다.
- 2026-10-27 (설정·유리 시트): 처음 화면 오른쪽 위 톱니바퀴와 서재의 ⋯ 메뉴에서 여는 설정 화면을 추가했습니다. 화면 모드(시스템 설정·라이트·다크)를 고르면 앱 창 전체(시트·서재 읽기 화면 포함)에 바로 적용되고 다시 켜도 유지되며, 도구 막대의 불투명 모드도 여기서 바꿀 수 있습니다. 설정·Sidecar 안내·맥 연결 시트를 기본 목록 대신 잉크 배경 위 유리 카드(`GlassSheet`·`GlassSection`·`GlassChoice`, `iPad/InkGlass.swift`)로 바꿨습니다. 시뮬레이터에서 톱니바퀴로 설정을 열어 라이트→다크 전환, 재실행 후 유지, Sidecar 안내와 맥 연결 시트의 라이트·다크 화면을 스크린샷으로 확인했습니다(`-appearance light|dark|system` 실행 인자). 맥 연결 시트에서 실제로 코드를 넣어 연결하는 흐름과 실기 유리 가독성은 확인하지 않았습니다.
- 2026-10-27 (흑백 잉크 테마): 처음 화면과 서재의 보라·파랑 배경을 잉크 테마로 바꾸고, 시스템 화면 모드를 따르게 했습니다(이전에는 항상 다크). 다크 모드는 숯색 번짐에 블루블랙이 살짝 도는 검정, 라이트 모드는 미색 종이에 옅은 잉크 번짐이고, 로고와 글자는 각 모드의 잉크색(흰색/검정)입니다. iPad 시뮬레이터에서 두 모드의 처음 화면·서재를 스크린샷으로 확인했고, 맥 화면·서재 읽기 화면과 실기 유리 가독성은 확인하지 않았습니다.
- 2026-10-27 (서재 책 모양): 서재의 책을 실제 양장본처럼 바꿨습니다. 표지 오른쪽에 쪽수에 따라 두꺼워지는 책장 단면(종이 결), 등 쪽 접힘 홈과 빛, 책장에 닿는 그림자를 넣고, 표지 이미지가 없는 책은 정해진 북클로스 색(남색·적갈색·녹색 등 8가지)에 금박 제목과 테두리선을, 표지 이미지가 있는 책은 천 등싸개(반양장)를 붙였습니다. 책 높이를 조금씩 다르게 하고, 필기가 있는 책은 아래로 늘어진 가름끈으로 표시하며, 유리 선반을 호두나무 선반으로 바꿨습니다. iPad 시뮬레이터 빌드와 세로 화면 스크린샷으로 확인했고, 가로 배치·책 누르기 애니메이션·실기 화면은 확인하지 않았습니다.
- 2026-10-27 (보안 수정): 페이지 주소의 `?review=`는 올바른 리뷰 ID일 때만 쓰고 API 경로에 넣을 때 인코딩합니다(조작한 링크가 필기 전체 지우기로 이어질 수 있었음). 페이지 지우기·저장은 빈 `page`를 거부하고, manifest는 `Sec-Fetch-Dest: manifest`일 때만 토큰을 담으며, iPad 가져오기는 HTML을 받지 않습니다(PDF·Office만). 서버 검사 22개 포함 전체 통과, 실기 iPad 설치.
- 2026-10-27 (서재·공개 준비): 문서 필기 모드를 **서재**로 바꾸고 `iPad/LibraryView.swift`에 유리 책장(종류별 책장, 첫 쪽 표지·천 표지, 필기 책갈피, 이어서 쓰기, 변환 중 표시, 검색, iPad 파일 가져오기)을 추가했습니다. 서버에 책 정보(`kind`·`cover`·`pageCount`)와 `POST /__pr/api/import`를 더했고 `pencil-review/`를 `library/`로 옮겼습니다. Sidecar판 소스를 `sidecar/`로 합치고 `-padMode` 실행 인자를 추가했습니다. `scripts/test-all.sh` 전체 통과(30 + 맥 컴파일, 서버 20, Sidecar 391), 시뮬레이터에서 책장·이어서 쓰기·책갈피 화면과 책 주소(303→200)를 확인했습니다. 가로 배치, 책을 눌러 펼치기·가져오기 흐름은 확인하지 않았습니다. 공개 전 보안 점검으로 서재 서버가 다른 사이트에서 보낸 변경 요청을 거부하고(Origin 검사), 페이지 스크립트가 읽는 manifest에는 토큰을 넣지 않으며, 맥이 틀린 연결 코드 3번 뒤 코드를 바꾸고, 서재 웹 뷰가 서버 밖으로 이동하지 않도록 했습니다(서버 검사 21개).

## 도구 선택 UI 참고

별도 Sidecar 버전에도 도구별 색·굵기 저장, 이름이 붙은 큰 도구 버튼, 선 미리보기 설정창을 적용했습니다. Sidecar 버전은 모델·렌더링 391개 검사, 별도 패널 UI 검수와 빌드·서명 검사를 통과했습니다. 이 폴더의 iPad 네이티브 버전과는 별도 앱입니다.

[Goodnotes](https://support.goodnotes.com/hc/en-us/articles/7353756785679-Write-and-customize-ink-with-the-Pen-tool)의 색·굵기 바로 선택과 재탭 설정, [Notability](https://support.gingerlabs.com/en-us/articles/16300108-getting-started-with-notability)의 도구별 프리셋, [Apple Markup](https://support.apple.com/en-ie/guide/ipad/ipad6350b8dc/ipados)의 접을 수 있는 도구 막대를 참고했습니다. InkBridge에서는 화면을 가리지 않도록 하단에 작게 두고, 도구를 바꿔도 필기 화면의 좌표계가 달라지지 않게 적용했습니다.
